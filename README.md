# 小红书业务关键词与矩阵内容

**把你的业务，翻译成客户真正会搜索的问题。**

`xhs-business-keywords` 是一个给 AI 助手使用的 Skill。它根据你卖什么、服务谁、实际能解决什么问题，在小红书核查搜索关键词，筛出值得覆盖的方向，再整理成与业务相关的内容地图。

它处理的典型问题是：**笔记发了不少，也有人看，但吸引来的人并不需要你的服务。**

## 什么时候用

- 准备做小红书，不知道目标客户会搜什么。
- 已经做账号或内容矩阵，但选题与业务连接不够紧密。
- 知道行业词，却没想到客户会用哪些人群词、场景词和问题词。
- 搜到很多相关词，不知道哪些该主攻、辅助或排除。
- 希望员工有依据地选题，而不是每天凭感觉追热点。

不必等业务介绍写得很完整才开始。已有上下文会继续使用，只补问会影响选词的关键信息。

## 你可以这样说

### 从业务开始，找精准关键词

```text
调用 xhs-business-keywords。

我做女性婚恋拓圈，帮助想找优质对象的女生，增加认识合适单身男性的机会。
我提供的是认识渠道和机会，不是情感挽回服务。

请根据我的业务扩散关键词，不局限于“上嫁、优嫁”。
使用已登录的小红书浏览器，核查真实搜索建议，
筛出主攻词、辅助词和排除词，说明理由。
```

### 给已有业务做内容检查

```text
调用 xhs-business-keywords。

我在杭州做家庭开荒保洁，主要服务刚装修完准备入住的家庭。
这是我们最近的选题：……
请判断哪些内容会吸引客户，哪些可能吸引求职者或同行，
再核查值得覆盖的小红书搜索词。
```

### 给矩阵团队安排选题

```text
调用 xhs-business-keywords。

我的产品是……，客户是……，实际交付是……。
团队目前有……人、……个真实账号，可用案例和素材是……。
请先核查客户搜索的问题，再按业务匹配程度筛选，
给出不同账号应回答的问题、所需证据和咨询承接方式。
```

也可以只要求一个环节，例如：“只查人群词”“只筛这份词库”“只给主攻词对应的选题”。

## 你会得到什么

| 产出 | 帮你判断什么 |
| --- | --- |
| 业务事实卡 | 服务谁、交付什么、哪些需求不属于你的业务 |
| 真实关键词表 | 客户实际使用的表达，以及查询来源和核查状态 |
| 关键词取舍 | 哪些主攻、哪些辅助、哪些排除、哪些还需验证 |
| 人群与问题分类 | 谁在什么处境下，会开始寻找解决办法 |
| 内容地图 | 每组词应回答什么问题，如何连接你的产品或服务 |
| 素材缺口清单 | 缺哪些真实案例、说明、比较依据或服务事实 |
| 验证计划 | 后续如何用有效咨询和可归因成交调整方向 |

完整采集任务要求交付可筛选表格、原始记录和截图。未取得或未保存的证据会明确标注，不把部分查询称为完整采集。

## 它怎样判断一个词值不值得做

不是含有行业字眼就收录，也不是互动多就推荐。

判断顺序是：

1. **搜这个词的人，是不是你想服务的人？**
2. **他当前的问题，你的实际交付能不能解决？**
3. **地域、条件和服务范围是否匹配？**
4. **这个词是否有平台证据，还是待验证的猜想？**
5. **你有什么真实材料，能回答他购买前的疑问？**

例如，假设业务是帮助女性拓展择偶机会：

| 候选词 | 处理方向 | 原因 |
| --- | --- | --- |
| 圈子小去哪认识合适对象 | 核查后可考虑主攻 | 寻找认识对象的渠道，与交付直接相关 |
| 高质量相亲渠道 | 核查后可考虑主攻 | 既关注渠道，又关注对象适配 |
| 男朋友不愿意付出 | 辅助或排除 | 可能需要现有关系咨询，不一定需要拓圈 |
| 资源池 | 待验证 | 可能是经营者用语，而非客户搜索表达 |
| 优嫁婚车 | 排除 | 实际是婚庆需求，字面相关但业务不相关 |

**上表是判断示例，不是实时热词榜，也不表示所有业务都应使用这些词。**

## 关键词如何变成矩阵内容

一组主攻词，需要对应一个客户问题：

> 搜什么 → 谁在搜 → 遇到什么障碍 → 你的服务如何相关 → 用什么证据回答 → 如何继续咨询

覆盖的方向可以包括：

- **需求问题**：客户遇到了什么困难。
- **人群场景**：谁在什么情况下需要帮助。
- **渠道方案**：客户正在找哪些解决办法。
- **比较决策**：靠谱吗、适不适合、怎么选。
- **产品核实**：你的服务包含什么、适用条件是什么。

矩阵不等于多个账号重复换标题。一人一号也可以先验证不同问题；只有真实角色、素材和负责人足够时，才建议扩展账号。

| Skill | 主要职责 |

| 本 Skill：`xhs-business-keywords` | 把业务转成客户问题，判断关键词匹配程度，并连接内容与咨询 |

## 安装

在终端运行：

```bash
npx -y skills add karrylee400/xhs-business-keywords -g --all
```

需要支持本地 Skills 的 AI 助手。安装后可直接说：

```text
调用 xhs-business-keywords，根据我的业务调研精准客户关键词，并生成矩阵内容方向。
```

不同应用的技能发现方式可能不同；如未显示，请按该应用的方式刷新技能或新建对话。

## 使用前准备什么

最有帮助的是以下信息；不清楚的可以先留空：

- 产品或服务，以及实际交付。
- 希望服务的客户和不适合的客户。
- 服务城市或地域限制。
- 客户常问的问题、现有选题或词库。
- 可公开使用的案例、素材和服务说明。
- 需要完整平台调研时，可访问小红书的浏览器与登录状态。

浏览器不可用时，只能提供明确标注的候选方向，不能冒充已完成平台检索。遇到登录或验证码，需要用户处理。

## 能力边界与验证状态

- 搜索联想词不等于搜索量，单次观察不代表全平台。
- 笔记互动不能证明用户会为你的服务付费。
- 创作建议与平台原词分开，不编造案例、评论、截图或效果。
- 不自动发布笔记、发送私信或承诺成交。
- 不上传客户隐私、账号凭据或未经授权的案例。
