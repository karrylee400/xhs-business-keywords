根据实际业务与目标客户，核查小红书真实搜索词，筛选主攻词、辅助词与排除词，并转为与服务相关的矩阵内容。

## 安装

发布到 karrylee400/xhs-business-keywords 后可尝试：

```bash
npx -y skills add karrylee400/xhs-business-keywords -g --all
```

此安装命令尚未经过远端安装验证。

## 使用

> 调用 xhs-business-keywords。我的业务是……，客户是……，实际交付是……。请核查小红书真实关键词，筛选与业务匹配的词并生成内容地图。

## 环境与范围

需要支持本地 Skill 的 AI 助手，以及能够访问小红书的浏览器工具与用户登录状态。可配合 yao-geo-xiaohongshu 完成两层采词与表格导出，配合 xhs-zhengzhou-playbook 编排内容；未安装时按技能正文执行并披露缺口。仓库不包含这两个第三方技能。

平台联想词不代表搜索量，内容建议不代表成交保证。不会自动发布内容或发送私信。请勿将客户个人信息、登录凭据或私密案例上传公开仓库。
